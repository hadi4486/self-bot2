# سلف‌بات تلگرام (Telethon)

## نصب روی Railway (روش اصلی)

نکته مهم: چون سرورهای Railway ترمینال تعاملی برای وارد کردن کد تایید تلگرام
ندارن، باید مرحله لاگین (گرفتن Session String) رو **اول روی سیستم خودت** انجام
بدی، بعد فقط همون رشته رو به Railway بدی.

**۱) گرفتن Session String روی سیستم خودت (یک‌بار، قبل از دیپلوی)**
```
pip install telethon python-dotenv
python generate_session.py
```
(قبلش API_ID و API_HASH رو توی یک فایل `.env` کنار `generate_session.py` بذار،
یا مستقیم داخل خود اسکریپت جایگزین کن.) شماره‌تلفن و کدی که تلگرام می‌فرسته رو
وارد کن؛ در آخر یک رشته طولانی چاپ می‌شه — همینو نگه دار.

**۲) دیپلوی روی Railway**

از طریق گیت‌هاب (پیشنهادی):
1. این پوشه (`main.py`, `requirements.txt`, `Procfile`, `railway.json`) رو به
   یک ریپوی گیت‌هاب پوش کن.
2. توی Railway → **New Project → Deploy from GitHub repo** → ریپو رو انتخاب کن.
3. Railway به‌خاطر `requirements.txt` خودش تشخیص می‌ده پروژه پایتونیه و با
   Nixpacks بیلدش می‌کنه. `railway.json` هم دستور اجرا (`python main.py`) رو
   مشخص کرده، پس نیازی به تنظیم دستی Start Command نیست.

یا از طریق CLI:
```
npm i -g @railway/cli
railway login
railway init
railway up
```

**۳) تنظیم متغیرهای محیطی**

توی داشبورد پروژه → تب **Variables** این‌ها رو اضافه کن:
- `API_ID`
- `API_HASH`
- `SESSION_STRING` (همونی که مرحله ۱ گرفتی)
- اختیاری: `PREFIX`, `TIMEZONE_OFFSET`, `CLOCK_INTERVAL`, `STATS_FILE`

بعد از ست‌کردن متغیرها، Railway خودش سرویس رو ری‌استارت می‌کنه و بات روشن می‌شه.
چون Railway (برخلاف Replit رایگان) پراسس رو به‌خاطر بی‌فعالیتی نمی‌خوابونه،
هیچ تریک keep-alive یا وب‌سروری لازم نیست — همین `worker: python main.py`
کافیه.

⚠️ **نکته درباره‌ی `notes.json` (و مشابه‌هاش):** این فایل‌ها به‌صورت پیش‌فرض
روی دیسک محلی کانتینر ذخیره می‌شن و با هر دیپلوی جدید پاک می‌شن. همین موضوع
برای `autopost.json`, `assistant.json`, `font_state.json` و `stats.json` هم
صدق می‌کنه. برای دائمی‌کردنشون:
1. توی Railway یک **Volume** به سرویس وصل کن و یک مسیر Mount مشخص کن (مثلاً `/data`).
2. متغیرهای محیطی مربوطه رو توی Variables اضافه کن، مثلاً `NOTES_FILE=/data/notes.json`
   و برای آمار: `STATS_FILE=/data/stats.json`.
3. سرویس رو Redeploy کن.

کد از همون متغیرها استفاده می‌کنه، پس نیازی به تغییر بیشتری نیست.

## نصب روی Replit (روش جایگزین)

1. یک Repl جدید از نوع **Python** بساز و این ۴ فایل رو داخلش آپلود کن:
   `main.py`, `requirements.txt`, `generate_session.py`, `.env.example`
2. توی Shell ری‌پلیت بزن:
   ```
   pip install -r requirements.txt
   ```
3. توی تب **Secrets** (آیکون قفل) این مقادیر رو اضافه کن:
   - `API_ID`
   - `API_HASH`
   - `PREFIX` (اختیاری، پیش‌فرض `.`)
   - `TIMEZONE_OFFSET` (اختیاری، پیش‌فرض `3.5` برای تهران)
   - `CLOCK_INTERVAL` (اختیاری، پیش‌فرض `60` ثانیه)
4. یک‌بار دستور زیر رو اجرا کن تا لاگین کنی و Session String بگیری:
   ```
   python generate_session.py
   ```
   شماره‌تلفن و کد تاییدی که تلگرام می‌فرسته رو وارد کن. در انتها یک رشته طولانی
   چاپ می‌شه — همون رو هم به Secrets اضافه کن با نام `SESSION_STRING`.
5. حالا `main.py` رو اجرا کن (دکمه Run). دیگه لازم نیست دوباره لاگین کنی.

## استفاده

پیشوند پیش‌فرض `.` است. مثلاً بنویس `.راهنما` تا لیست کامل دستورات رو ببینی.

دستورها فارسی‌ان (مثل `.راهنما`, `.پینگ`, `.منشی`)، ولی نام‌های انگلیسیِ قدیمی
(`.help`, `.ping`, `.assistant`, …) هم برای سازگاری هنوز کار می‌کنن - هرکدوم
راحت‌تره همونو استفاده کن.

## ارسال خودکار متن به گروه

با `.ارسال‌خودکار` می‌تونی یه متن رو با فاصله‌ی زمانی دلخواه به یک یا چند گروه که
خودت انتخاب می‌کنی بفرستی. برای شروع:
```
.ارسال‌خودکار متن میو
.ارسال‌خودکار افزودن        (این دستور رو داخل خودِ گروه مقصد بفرست)
.ارسال‌خودکار فاصله 5
.ارسال‌خودکار روشن
```
برای دیدن وضعیت کامل کافیه فقط `.ارسال‌خودکار` رو بفرستی.

⚠️ فاصله‌های خیلی کم (زیر ۵ دقیقه) و پیام‌های تکراری، ریسک تشخیص به‌عنوان
اسپم توسط سیستم‌های خودکار تلگرام رو بالا می‌برن؛ سعی کن فاصله رو معقول نگه
داری و از این قابلیت فقط توی گروه‌های خودت استفاده کنی.

همین‌طور تنظیمات ارسال‌خودکار (مثل notes) روی دیسک محلی ذخیره می‌شه و با هر
دیپلوی پاک می‌شه؛ اگه Volume وصل کردی، می‌تونی `AUTOPOST_FILE=/data/autopost.json`
رو هم به Variables اضافه کنی تا دائمی بمونه.

با `.آمار` هم می‌تونی هر وقت خواستی ببینی چندتا ارسال‌خودکار موفق/ناموفق بوده
(به بخش «📊 آمار سلف‌بات» پایین‌تر نگاه کن).

## منشی چت (پاسخ خودکار هوشمند)

با `.منشی` می‌تونی یه منشی بسازی که وقتی خودت واقعاً آفلاینی، خودکار به
پیام‌ها جواب بده - و وقتی برگردی (مثلاً گوشیت فعال بشه) خودش خاموش بشه. برای
شروع:
```
.منشی متن سلام 👋 فعلاً آنلاین نیستم، پیامتون رو دیدم و به‌زودی جواب می‌دم.
.منشی حالت منشن
.منشی تأخیر 3
```
همین! دیگه لازم نیست دستی روشن/خاموشش کنی - تشخیص آنلاین/آفلاین خودکاره (هر
۳۰ ثانیه سشن‌های فعال اکانتت رو چک می‌کنه: اگه سشن دیگه‌ای غیر از همین اسکریپت
به‌تازگی فعال بوده، یعنی خودت آنلاینی و منشی خاموش می‌مونه). اگه خواستی دستی
override کنی: `.منشی روشن` یا `.منشی خاموش` (توجه: با اولین فعالیت
واقعی‌ات دوباره خودکار اصلاح می‌شه).

⚠️ **درباره‌ی حالت‌ها:** پیش‌فرض `منشن` هست - یعنی فقط وقتی توی گروه تگ یا
ریپلای بشی جواب می‌ده (توی پیوی همیشه جواب می‌ده، چون پیوی ذاتاً خطاب به
خودته). حالت `خودکار` رو فقط زمانی روشن کن که واقعاً می‌خوای به **همه‌ی** پیام‌های
یه چت جواب بده، حتی بدون تگ - وگرنه توی گروه‌های شلوغ شبیه اسپم می‌شه.

به هر شخص فقط یک‌بار در هر نشست جواب داده می‌شه (نه به هر پیام)، تا اسپم نشه.
با `.منشی مستثنی` / `.منشی شامل` هم می‌تونی چت‌های خاص رو از
قانون کلی مستثنی یا همیشه‌فعال کنی. برای دیدن وضعیت کامل: `.منشی`.

**قفل دستی:** با `.منشی روشن` یا `.منشی خاموش` می‌تونی دستی روشن/خاموشش
کنی - و از اون لحظه، تشخیص خودکار آنلاین/آفلاین دیگه دست بهش نمی‌زنه (حتی اگه
واقعاً آفلاین بشی، خاموش می‌مونه؛ حتی اگه آنلاین بشی، روشن می‌مونه). برای
برگردوندن به حالت خودکار: `.منشی خودکار`.

## سرگرمی

چندتا دستور سرگرمی/بازی هم هست:
```
.تایپ‌زنده سلام دنیا      (افکت تایپ زنده حرف‌به‌حرف)
.پیش‌تایپ سلام            (شبیه‌سازی تایپ قبل از ارسال واقعی)
.معکوس سلام               (معکوس‌کردن متن)
.طنز متن شما               (حروف بزرگ‌وکوچکِ متناوب، طنزآمیز)
.تاس 4                    (تاس واقعی می‌ندازه تا عدد ۴ بیاد)
.شیرخط                    (شیر یا خط)
.تصادفی 1 100              (یه عدد تصادفی بین ۱ تا ۱۰۰)
.انتخاب پیتزا, برگر, سوشی  (انتخاب تصادفی بین چند گزینه - با کاما یا فاصله جدا کن)
.سنگ‌کاغذقیچی سنگ          (بازی سنگ‌کاغذقیچی با بات)
.اسلات                    (ماشین اسلات با سه نماد تصادفی)
.جادوگر فردا هوا خوبه؟     (پاسخ تصادفیِ توپ جادویی به سوال بله/خیری)
.عشق‌سنج علی و سارا         (درصد عشق‌سنجِ شوخی؛ برای یه جفتِ ثابت همیشه یکسانه)
.این‌یا‌اون                 (یه سوالِ «این یا اون» تصادفی)
```

**بازی حدسِ عدد:**
```
.حدس شروع        (یا .حدس شروع 500 برای بازه‌ی بزرگ‌تر - پیش‌فرض ۱ تا ۱۰۰)
.حدس 50          (حدس بزن - راهنمای بالاتر/پایین‌تر می‌ده)
.حدس لغو         (لغو بازیِ فعال)
```
هر چت یه بازیِ مستقل داره. توجه کن این بازی فقط توی حافظه نگه داشته می‌شه، پس
با ری‌استارت سرویس بازیِ در حال اجرا از بین می‌ره (که طبیعیه، چون یه سرگرمیِ
کوتاه‌مدته، نه بخشی از تنظیمات دائمی).

## فونت پیام

با `.قلم` می‌تونی متن رو به فونت‌های مختلف تبدیل کنی - هم به‌صورت یه‌بار، هم
به‌صورت خودکار روی همه‌ی پیام‌های عادی‌ای که می‌فرستی:
```
.قلم فهرست                 (لیست کامل با نمونه)
.قلم bold سلام Hello       (تبدیل یه‌بار)
.قلم تنظیم fa_kashida       (تنظیم فونت پیش‌فرض)
.قلم روشن                  (از این به بعد همه‌ی پیام‌هات خودکار فونت می‌شن)
.قلم خاموش                 (خاموش کردن حالت خودکار)
.قلم وضعیت                 (وضعیت فعلی)
```

سه دسته فونت داری (۲۷ مورد):
- **انگلیسی** (۱۰ فونت: `bold`, `italic`, `bold_italic`, `script`, `fraktur`,
  `sans_bold`, `monospace`, `smallcaps`, `circled`, `upside_down`) - از بلاک
  یونیکد Mathematical Alphanumeric Symbols، فقط روی حروف لاتین اثر می‌ذارن.
- **فارسی** (۱۳ فونت). سه‌تاشون واقعاً روی شکلِ رندرشده‌ی حروف اثر می‌ذارن، نه
  فقط دور متن دکوراسیون:
  - `fa_kashida` — کشیدگی واقعی با تطویل عربی (ـ)، دقیقاً همون تکنیک خوشنویسی
  - `fa_underline` — زیرخط واقعی زیر تک‌تک حروف
  - `fa_strike` — خط‌خوردگی واقعی روی تک‌تک حروف

  بقیه (`fa_spaced`, `fa_stars`, `fa_flowers`, `fa_brackets`, `fa_elegant`,
  `fa_ribbon`, `fa_diamond`, `fa_wave`, `fa_boxed`, `fa_hearts`) تزئینی‌ان.

  ⚠️ یه نکته‌ی صادقانه: یونیکد یه بلاک نایاب هم به اسم «Arabic Mathematical
  Alphabetic Symbols» داره که شبیه بولد/ایتالیک واقعی برای عربی/فارسیه، ولی
  پشتیبانی فونتش روی خیلی از گوشی‌ها ضعیفه (ممکنه باکس خالی نشون بده) و چون
  این محیط به اینترنت وصل نیست نتونستم نگاشت دقیق کدپوینت‌هاش رو تأیید کنم -
  به همین دلیل عمداً پیاده‌سازیش نکردم تا ریسک نمایش کاراکتر اشتباه نره بالا.
- **ترکیبی** (۴ فونت: `mix_bold`, `mix_italic`, `mix_script`, `mix_mono`) -
  حروف لاتین رو فونت می‌کنن و کل متن (فارسی+انگلیسی) رو با نماد تزئینی قاب
  می‌گیرن.

می‌تونی روی یه پیام ریپلای کنی و فقط `.قلم <نام>` بزنی، لازم نیست متن رو
دوباره تایپ کنی.

⚠️ **درباره‌ی حالت خودکار:** چون تلگرام پیام رو اول واقعی می‌فرسته و بعد ربات
ادیتش می‌کنه، یه لحظه‌ی خیلی کوتاه متنِ اصلی (بدون فونت) قابل‌دیدنه، بعد جایگزین
می‌شه. این محدودیت ذاتیِ همه‌ی سلف‌بات‌هاست، چون امکان تغییردادن پیام قبل از
ارسال واقعی وجود نداره. دستورهای خودِ ربات (هر چیزی که با `.` شروع بشه) از
فونت خودکار مستثنی‌ان، پس روشن‌بودنش باعث خراب‌شدن بقیه‌ی دستورها نمی‌شه.

## 📊 آمار سلف‌بات

با `.آمار` هر وقت خواستی می‌تونی ببینی سلف‌بات واقعاً چه وضعیتی داره:
```
.آمار         (خلاصه‌ی کلی: دستورات، پیام‌ها، ارسال‌خودکار، خطاها، زمان فعالیت + پراستفاده‌ترین دستورها و چت‌ها)
.آمار چت‌ها     (آمار کامل به‌تفکیک هر چت)
.آمار بازنشانی  (پاک‌کردن شمارنده‌ها و شروع از صفر)
```
دقت کن «تعداد خطاها» فقط خطاهای سیستمی/پس‌زمینه (مثل خطای شبکه یا API تلگرام)
رو می‌شمره، نه خطاهایی که خودت با ورودی اشتباه به یه دستور ایجاد می‌کنی (مثل
یه عبارت ریاضی نامعتبر توی `.حساب`).

آمار توی `stats.json` ذخیره می‌شه (هر ۶۰ ثانیه) تا با ری‌استارت از دست نره؛
مثل بقیه‌ی فایل‌های وضعیت، اگه Volume وصل کردی می‌تونی `STATS_FILE=/data/stats.json`
رو هم به Variables اضافه کنی تا کاملاً دائمی بمونه.

## 💾 بکاپ‌گیری

با `.پشتیبان` چند جور بکاپ می‌تونی بگیری - همه به Saved Messages ارسال می‌شن:

```
.پشتیبان 200            (بکاپ متنیِ ۲۰۰ پیام آخر همین چت)
.پشتیبان json 200       (همون، ولی خروجی JSON ساختاریافته برای پردازش برنامه‌ای)
.پشتیبان رسانه 200      (دانلود و فوروارد فایل‌های رسانه‌ی ۲۰۰ پیام آخر)
.پشتیبان چت‌ها           (لیست کامل چت‌ها/گروه‌ها/کانال‌های اکانتت)
.پشتیبان تنظیمات        (بکاپ کامل تنظیمات بات: یادداشت، منشی، ارسال‌خودکار، فونت، ساعت، آمار)
```

سقف پیش‌فرض ۲۰۰۰ پیام برای بکاپ‌های متنی/JSON و ۵۰ فایل برای بکاپ رسانه‌ست -
برای جلوگیری از تایم‌اوت و محدودیت آپلود تلگرام.

**بازیابی تنظیمات بعد از ری‌دیپلوی:** همون‌طور که بالاتر اشاره شد، فایل‌های
وضعیت (`notes.json`, `autopost.json`, …) بدون Volume با هر دیپلوی پاک می‌شن.
اگه نمی‌خوای Volume وصل کنی، می‌تونی به‌جاش قبل از هر دیپلوی `.پشتیبان تنظیمات`
رو بزنی و فایل خروجی رو نگه داری؛ بعد از دیپلوی جدید، همون فایل رو (توی
Saved Messages یا هرجایی که نگهش داشتی) به بات فوروارد کن و روش ریپلای کن:
```
.بازیابی
```
همه‌ی تنظیمات (یادداشت‌ها، منشی، ارسال‌خودکار، فونت، ساعت) برمی‌گردن سرجاشون.
این روش جایگزین کامل Volume نیست (چون دستی‌ست)، ولی برای دیپلوی‌های کم‌تعداد
یا بک‌آپ اضطراری کافیه.

## نکات امنیتی

- فایل `.env` یا Session String رو جایی منتشر نکن — معادل رمز اکانتته.
- دستورات مدیریتی گروه (`.اخراج` / `.مسدود` / `.ارتقا` / `.تنزل`) رو فقط توی
  گروه‌های خودت که ادمینشون هستی استفاده کن.
- فاصله `CLOCK_INTERVAL` رو خیلی کم نکن (زیر ۳۰ ثانیه) تا ریسک محدودیت از طرف
  تلگرام کم بمونه.
- فایل خروجیِ `.پشتیبان تنظیمات` رو جای امنی نگه دار: شامل رمز عبور یا Session
